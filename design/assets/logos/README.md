# Логотипы блока «Опыт работы с компаниями»

Файлы кладутся сюда под именами из списка. Вёрстку при этом менять не нужно:
страница сама подхватывает файл и убирает текстовую подпись-заглушку.

| Файл                      | Компания             |
|---------------------------|----------------------|
| `citibank.svg`            | Citibank             |
| `deloitte.svg`            | Deloitte             |
| `ford.svg`                | Ford                 |
| `sanofi.svg`              | Sanofi               |
| `kraft-foods.svg`         | Kraft Foods          |
| `rosnano.svg`             | РОСНАНО              |
| `inter-rao.svg`           | Интер РАО            |
| `gazprom-pererabotka.svg` | Газпром переработка  |

Формат: предпочтительно SVG. Если логотип пришёл растром, файл можно положить
с тем же именем и расширением `.png`, `.jpg` или `.webp` — страница переберёт
расширения в порядке `svg → png → jpg → webp` и возьмёт то, что найдёт.

## Требования к файлам

- Знак обрезан по краям изображения, без собственных полей: поля задаёт ячейка.
- Без цветной подложки и без рамки — ячейка белая, подложка в знаке даёт
  «плашку», которая перетягивает ряд на себя.
- Одна визуальная высота приходит из вёрстки: знак упирается в 78% по ширине
  ячейки или в свою высоту. Высота задаётся на ячейке в `index.html`
  свойством `--logo-h` (по умолчанию 38px): однострочный знак при одной
  высоте читается крупнее двухъярусного, поэтому она подбирается по месту.
  Сейчас: Sanofi 34px, Kraft Foods 40px, РОСНАНО 44px,
  Газпром переработка 50px.
- Растр — минимум 2x от 38px по высоте, то есть от 80px; для широких
  горизонтальных знаков ориентир по ширине — от 600px.
- В блоке логотипы показаны обесцвеченными и возвращают цвет при наведении,
  поэтому одноцветные версии знаков не обязательны — подойдут цветные.

Права на публикацию логотипов согласуются отдельно.
