# Simkin.ru — прототип главной страницы

Чёрно-белый прототип главной страницы для проекта переработки сайта Simkin.ru
как экспертной платформы по авторской системе эргономики Доктора Симкина.

Это прототип для согласования структуры, а не дизайн. Изображения показаны
серыми плашками, тексты обозначены линиями.

**Демо:** https://ivanweb1.github.io/simkin-prototype/

## Состав страницы

1. Первый экран
2. Чем подход отличается, схема из шести шагов
3. Кому полезен сайт
4. Основные направления работы
5. Об эксперте
6. Клиенты
7. Как работает подход
8. Форматы сотрудничества
9. Знания и статьи
10. Заявка
11. Сквозной блок призыва и подвал

## Как открыть локально

Достаточно открыть `index.html` в браузере. Зависимостей нет, стили внутри файла.
